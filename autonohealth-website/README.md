# AutonoHealth Website — Polished Static Prototype

Open `index.html` in any modern browser. No installation or web server is required for the core experience.

## Primary navigation

- Home
- Conditions
- Treatments
- Track
- Tools
- Shop
- About

The Learning Hub and Evidence Center remain available through contextual links and the footer. The former `kits.html` URL redirects to `shop.html`.

## Included prototype features

- Responsive multi-page design system
- Working site search
- Working Otto demonstration drawer
- Searchable and filterable condition and treatment libraries
- Four-level, indication-specific evidence rating framework
- Evidence-based starter content for twelve common conditions across cardiovascular, metabolic, sleep, allergy, neurological, digestive, respiratory, musculoskeletal, mental, kidney, and skin health
- Starter treatment monographs across lifestyle, medication, and natural-product categories
- Local-only daily tracker with automatic completion, custom number units, reorderable/removable defaults, reusable custom items, and contextual Otto encouragement
- BMI, Cockcroft–Gault, sleep debt, and caffeine half-life calculator demos
- Learning Hub, Evidence Center, Shop, privacy principles, and medical disclaimers
- Accessible focus states, labels, responsive navigation, and reduced-motion support

## Important production notes

This is a static front-end prototype. Before public launch, the medical content should receive documented qualified review. Production accounts, protected health data, AI, search, analytics, payments, email collection, and commerce require appropriate backend systems, privacy/security review, legal review, and ongoing editorial governance.
